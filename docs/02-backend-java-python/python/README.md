# Python Backend

This subfolder is dedicated to Python backend engineering and production FastAPI services.

## Planned study path

1. Core Python for backend engineers
2. FastAPI application architecture
3. Pydantic validation and API contracts
4. Async I/O, concurrency, and background work
5. SQLAlchemy, database transactions, and migrations
6. Testing with pytest and contract tests
7. Security with OAuth 2.0, OIDC, and JWT
8. Packaging, observability, Docker, and Kubernetes deployment

Python material will stay separate from Core Java so each backend learning path remains clear and progressive.
