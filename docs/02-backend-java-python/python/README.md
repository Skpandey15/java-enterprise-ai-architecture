# Python Backend

Python backend material is calibrated for engineers with **0–3 years of Python experience**. It develops practical skill from language basics through a production-ready FastAPI service.

## Main curriculum

- [Python Backend: Zero to Job-Ready (0–3 Years)](zero-to-job-ready/README.md)

The ten-chapter path covers:

1. Python runtime and language fundamentals
2. Collections, iteration and Pythonic coding
3. OOP, dataclasses, protocols and clean code
4. Exceptions, files, packages and environments
5. FastAPI, Pydantic and REST design
6. SQL, SQLAlchemy, transactions and migrations
7. Async I/O, threads, processes and background jobs
8. pytest, debugging and automated quality checks
9. Security, observability, Docker and deployment
10. A portfolio project, interview questions and readiness checklist

The goal is credible hands-on backend knowledge, not memorized definitions or exaggerated architectural claims.
