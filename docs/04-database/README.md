# Part 4 — Database

This part covers relational and NoSQL design, PostgreSQL, MongoDB, schema evolution, indexing, transactions, consistency, caching, partitioning, replication, high availability, recovery and distributed-data patterns.

## Featured learning track

- [Database: Zero to Expert](database-zero-to-expert/README.md) — twelve progressive, hands-on chapters from database fundamentals and SQL through PostgreSQL performance, NoSQL, high availability and expert system design.

## Architecture guides

- [Saga and Transactional Outbox](saga-and-transactional-outbox.md)
- [ADR-0001: PostgreSQL as the System of Record](../../adrs/0001-postgresql-system-of-record.md)

## Recommended path

1. Complete Chapters 1–3 for relational foundations, SQL and modelling.
2. Build the PostgreSQL lab in Chapters 4–8.
3. Add scale, NoSQL and operational capability in Chapters 9–11.
4. Complete the distributed-data capstone in Chapter 12.
5. Use the Saga/Outbox guide and ADR as architecture companions.

## Target capability

The learner should be able to design a correct schema, write and tune SQL, control concurrency, evolve production data safely, choose SQL versus NoSQL from evidence, plan HA and recovery, and defend distributed-data trade-offs in a senior system-design discussion.
