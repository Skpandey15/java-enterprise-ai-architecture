# Part 1 — Frontend

This part covers enterprise frontend engineering with React and TypeScript: component architecture, state management, API integration, accessibility, performance, security, testing, observability, and deployment.

## Study material

- [ReactJS: Zero to Job-Ready (0–3 Years)](react-zero-to-job-ready/README.md) — ten progressive chapters covering JavaScript, TypeScript, React, hooks, routing, forms, APIs, state management, testing, security, accessibility, performance, deployment and interviews.
- [AI-Assisted Interview Platform](../03-ai/ai-assisted-interview-platform.md) — an end-to-end React/TypeScript client with Keycloak login, API integration and browser trust boundaries.

## Recommended path

1. Complete the ReactJS Zero-to-Job-Ready chapters in order.
2. Build the Online Interview Portal milestone by milestone.
3. Connect it to a real backend and identity provider.
4. Add integration/E2E tests, performance evidence and CI/CD.
5. Study enterprise architecture and micro-frontends after mastering one deployable application.

## Target capability

| Experience | Expected outcome |
|---|---|
| 0–1 year | Build typed components, forms and REST-driven screens |
| 1–2 years | Design reusable features, tests and server-state flows |
| 2–3 years | Diagnose production issues and explain security, performance and architecture trade-offs |
